# Glossary

One row per recurring term. Decide once, then use it everywhere. QA reviews against this table.
Status: APPROVED by the project lead 2026-11-02 (decisions below are final).

## Decisions

1. **Title:** ザ・コンビニ３ ～あの町を独占せよ～ → **"The Conveni 3: Corner the Market!"** (the project lead's wording).
2. **コンビニ → "conveni"** in game text (plural "convenis"), the way Western games say "tycoon". Lowercase in
   running text, capitalized in titles and menus. Spelling "Conveni" matches the series logo. One early line
   explains it in the tutorial-mode description and the first tutorial page, e.g. "A conveni is a Japanese
   convenience store."
3. **Money:** yen, written `¥1,000,000`. Written-out text uses "¥100 million", "¥50 million". Numbers the game
   formats at run time get a code change to print `¥50,000,000` (the project lead: yes, if it can be done).
4. **Real brands stay:** LAWSON, Karaage-kun (からあげクン), LAWSON Pass, the LAWSON product lines in item blurbs.
5. **Honorifics:** contemporary policy, so they stay where people use them: えんぜるさん → **Angel-san**.
   Customers (お客さん) are just "customers"; 店員さん → "the clerks".
6. **Width:** fixed-size slots; letter-pair glyphs give about 1 byte per letter. Keep lines tight anyway.
7. **Places:** translate pun names (海賊湾 → Pirate Bay), keep plain place names in romaji.
