# Script pass 1: English fish names

## Fish renamed
| Japanese | Before | Now |
|---|---|---|
| サワラ | Sawara | Seerfish (also called: Spanish mackerel) |
| メイチダイ | Meichi bream | Bigeye bream |
| モロコ (the Kue, a Sea King) | Moroko | Kelp grouper (also called: Longtooth) |
| マフグ | Puffer | Purple puffer (also called: Puffer) |
| クロカジキ (a Sea King) | Black marlin | Blue marlin. This is what the species actually is, and the game's own alias says ブルーマーリン |
| イイダコ | Webfoot octopus | Rice octopus (also called: Webfoot octopus) |
| キアマダイ | Yellow tilefish | Gold tilefish |
| ワカシ / イナダ / ワラサ | Wakashi / Inada / Warasa | Yellowtail fry / Jr. yellowtail / Big yellowtail (the grown fish ブリ stays "Yellowtail") |

## "Also called" names changed from Japanese to English
Ma-aji → Horse mackerel, Nibe → Nibe croaker, Kobudai → Sheepshead, Kihada → Ahi, Magochi → Bartail flathead,
Hanadai → Sea bream, Bashokajiki → Billfish, Kyusen → Rainbow wrasse, Shosai puffer → Puffer, Kue → Longtooth,
Ink squid → Golden cuttle.

## Cooking notes
- tataki → minced, or seared for bonito
- katsuobushi → dried flakes
- arai → ice-washed sashimi
- shiokara → fermented
- kabayaki → glazed
- ankimo → liver
- karasumi → dried roe
- nanban → marinated
- oden → simmered in stew

## Follow-on changes
- Story, town and paper text that says "moroko", "kue" or "black marlin" now uses the new names. The kue line now reads "It's a kind of giant grouper, right?"
- The contest is now "Grouper Record". The items are now "Grouper rod 5m" and "Grouper hook".
- The lures are now "Kagura Yellowtail", "Kagura Tuna" and "Kagura Mackerel".
- ビシ (bishi) is now "feeder" everywhere: the fishing style, "Wire feeder" and "Plastic feeder", and the messages.
- The two beakfish hints now use the in-game names (beakfish → blackmouth, spot beakfish → whitemouth).
- The kabuto-yaki line now says "grill the head of the giant bluefin tuna".

## Left as they are
- Hook patterns: Sode, Iseama, Ryusen, Kaizu, Mutsu, Seigo. Tackle shops sell these under these names.
- Tackle terms: Sabiki, Egi, Tsuno jig, Burakuri.
- Japanese place names and people's names.
- The fish descriptions that explain how Japanese names change as yellowtail and Spanish mackerel grow.

## Fitting check
The newspaper headline holds only 14 letters (checked in the emulator), so fish names are capped at 14. That is why Spanish mackerel became Seerfish, Young yellowtail became Jr. yellowtail, and so on. The build now measures every line with an inserted name against the longest possible name. That caught three lines, which are now split: "Found / [bait]", "[creature] / attacks!" and "Defeated / [creature]". The keep net window was also still showing fish names in Japanese, and it's fixed now.
