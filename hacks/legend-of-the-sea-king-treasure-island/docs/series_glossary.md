# Nushi Tsuri series: shared English glossary

**Master reference:** `RiverKing_Glossary_v1.3.xlsx` in this folder (the tester's Super Legend of the River King
patch v1.3, every fish, creature, item, place and term with its Japanese). the tester asked on 2026-10-27 that all
the other patches follow it. This file lists how each game applies it and where a game has to differ.

Used by: Kawa no Nushi Tsuri 3 & 4 (GBA, v1.0), Kawa no Nushi Tsuri: Shizen-ha (PCE CD, v0.9.6), Umi no Nushi Tsuri (SFC, v1.1), Tsuri Tarou (SFC, v0.9.1).

## Rules (from the River King glossary)
- Same Japanese name = same English name. Japanese names are kept only where no English common name exists:
  Itomoroko, Mugitsuku, Tamoroko, Wataka, Higai.
- **Title Case** for names in lists, menus, records and item windows ("Masu Trout", "Ball Float", "Rice Ball").
  In running text (dialogue, signs, descriptions) common names are lower case ("a masu trout", "chum", "creel").
- River forms are Trout, sea-run forms Salmon: ヤマメ Masu Trout / サクラマス Masu Salmon,
  アマゴ Redspot Trout / サツキマス Redspot Salmon.
- Short forms only where space is tight, in the River King style: W.Crucian, Masu Tr., Bl. Bass, Sticklbk.
- ぬし = River King (Umi: 海のぬし = Sea King). Money in yen; counters 尾 匹 才 are dropped.
- Gear: サオ Rod, ウキ Float, オモリ Sinker, ハリ Hook. Styles: Float, Casting, Lure, Fly.
- Cooking notes keep Japanese dish names as River King does: Arai (あらい/洗), Kabayaki (蒲焼き),
  Bottarga (カラスミ), Narezushi (なれずし), Tsukudani (つくだに), Dengaku (田楽), Tsukeyaki (つけやき),
  Nibitashi (煮びたし); Not eaten (食べない), For sport (スポーツ用), Soup (吸物), Carp soup (コイこく).
- Status window: HP, Yen, EXP; battle command window "Cmd". Title/file menus: Start, New Game, Erase Data.
  Fishing Note columns: Got (釣果), Best (最長), Info (生活), Use (利用).
- Characters: 太郎 Taro, 京子 Kyoko.

## Per-game notes and deliberate differences
**Tsuri Tarou v0.9.1:** River King; Masu Trout; White Crucian (W.Crucian in the SELECT fish list's 11-letter
right column); paste bait; Taro. Records column 釣果 is Got, as in River King.

**Umi no Nushi Tsuri v1.1:** all fish, bait, gear, food, item and creature names in Title Case. Yen in the status
window; New Game / Erase Data. Shared fish match River King (Sea Bass, Black Porgy, Grass Puffer, Halfbeak, Goby,
Mullet). Kept on purpose because the sea game has both fish: メゴチ stays **Dragonet** (マゴチ is Flathead),
ゴカイ stays **Ragworm** (フクロイソメ is Lugworm), 丸セイゴ hook stays **Seigo Hook** (スズキ hook is Sea Bass Hook).
Kept for width: Plum Bento (Hinomaru Bento is 14 > 13), Postcard. フナムシ is Sea Slater as both bait and creature;
ナツメ型 is Date Sinker.

**Shizen-ha v0.9.6:** fish as above. Animals as River King where they fit 9 letters: Tanuki, Mt. Bat, Deer,
Macaque, Rat Snake, Moon Bear; kept Mouse (Field Mouse), Squirrel (Flying Squirrel) and Grizzly (Brown Bear) for
width. Menu slots are 4-6 letters, so these stay and dialogue uses the same words: Caddis (川虫), Midge (赤虫),
Paste (ねりえ, "paste bait" in dialogue), Worms, Magnet (磁石), Sparks (花火), Tub (たらい), Bag (びく menu; "creel"
in dialogue), Spud, Cake, Mint, Bun. Area names stay Glen / High / Mid / Low / Bay (4-letter slots; a different
river from River King's Stream / Creek / Plains / Coast). Fish guide labels: Length, Got, Use.

**Kawa no Nushi Tsuri 3 & 4 (GBA) v0.6:** fish, gear and style names as River King. Money Yen; status HP / Yen /
EXP; commands Fish, Go (いどう), Eat, Items, Gear, Bag, Cmd, Fight, Run. Width exceptions: **Bag** for びく in menus
("creel" in dialogue; the item is Creel S/M/L), **Pole** S/L for ふりだしザオ (Casting Rod / Lure Rod / Fly Rod S/L
for the others), Washtub (Tub where 4 letters), Little Bro / Big Bro (game 4 brother choice), Uocchi (うおっち, kept
as a name). Game 3 places: Stream, Upper Lake, Creek, Plains Lake, Mirage Lake. Food: Mandarin, Rice Ball, Bento.
Bait: Worms, Maggots, Insects, Bloodworm, Stream Bug, Paste Bait, Small Fish, Frog.
Lures: Spinner, Spinnerbait, Minnow, Crankbait, Popper, Spoon, Rubber Worm, Frog Lure. Flies: Mayfly, Caddis,
Diptera, Stonefly, each (Wet)/(Dry). Uocchi screens: Tank Settings (Depth Deep/Low, Current On/Off, Bottom
Sand/Rocks, Water Purity), Commands, Fish Status (Species, Length, Age, Fullness, Stress). Fishing Memo: Best,
Avg., Total. Game 4 windows: Cooler, Bug Cage, Flowers, Level (EXP, Fish Caught, To Next Level).
v0.7: shop titles Rods, Lures, Hooks, Bait, Flies (ケバリ and キジバリ), Items, Catalog (つうはん), Prices (ねたん),
Total (こうけい). Prices use ¥ after the number where 円 was one tile. Memo stamps: 育成 = Raised, 大物 = Big One.
Uocchi help text says "sand or rocks" to match the Sand / Rocks options.
v0.8: building plaques as pictures like Umi / Shizen-ha (釣 hook, 魚 fish, 宿 INN); 万 (general store) = shopping bag.
v0.9: game 4 memo books Fish / Shell / Bug / Flower Memo (つり / かい / 虫 / 花メモ): 最高 Best, 基本 Size (standard
length; game 3's 平均 stays Avg.), 総数 Total, 価値 Value, ランク Rank, 大物 stamp Big One; counters 尾 個 匹 本 dropped.
v0.95: title logos use the western names: collection "Legend of the River King Advance Collection", Kawa 3 "Legend
of the River King GBC", Kawa 4 "Legend of the River King 2" (the tester's art).
v1.0: game 4 item names follow game 3: Pole S/L (ふりだしざお), Worms (ミミズ bait), Rubber Worm (ワーム lure), Fly
(ギジバリ, as the shop's Flies title); ドクダミ = Fish Mint. Max HP (not "stamina") for さいだいたいりょく. The link
screen calls game 4 "Legend of the River King 2".

## Graphics
Town/village plaques use the Umi no Nushi art: INN as text, a hook for the tackle shop, a fish for the fish shop
(Umi: UmiToolkit/build/field_signs.py; Shizen-ha: tools/signs.py), as River King's signs do. Shizen-ha's dango
banner shows a dango skewer.
