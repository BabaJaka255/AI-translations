# Source: Super Legend of the River King

This folder has the full build for the v1.3 patch, plus the research tools and engine notes. It contains no ROM data and no game text. You need your own ROM to build.

**Start with [`ENGINE_NOTES.md`](ENGINE_NOTES.md).** It explains how the game's text, fonts, compression and screens work, and lists every address the patch touches.

## Rebuilding the patch
Requirements:
* Python 3.10 or newer
* `pip install pillow openpyxl numpy`

```
mkdir rom && cp "Kawa no Nushi Tsuri 2 (Japan).sfc" rom/   # CRC32 716D3EFF, no header
python3 analysis/dump_script.py      # reads the script from your ROM into out/script.json
python3 build/build_patch2.py        # writes out/knt2_en.ips and out/knt2_en.sfc
```

The result is byte-identical to `patches/KawaNoNushiTsuri2_EN_v1.3.ips`. The patched ROM's CRC32 is `8F2E0D10`.

## Editing the script
```
python3 build/script_io.py export out/script.xlsx   # original + English side by side, with limits
python3 build/script_io.py import out/script.xlsx   # checks every line, writes build/user_edits.py
python3 build/build_patch2.py
```

## Layout
| Path | What it is |
|---|---|
| `build/build_patch2.py` | Main build. It expands the ROM to 2 MB, encodes and relocates the English script, installs the text hooks, runs every module below, fixes the checksum and writes the IPS |
| `build/translations.py`, `tr_batch2.py`, `tr_batch3.py`, `user_edits.py` | The English script, by string id. `user_edits.py` is generated by the workbook import and takes priority over the others |
| `build/zones_en.py`, `fish_desc_en.py` | English names for fish, gear, items and creatures, and the Fishing Note descriptions |
| `build/labels.py`, `ui_font.py`, `glyph_patch.py` | Menu label art, the window UI font, and the yen and counter glyphs |
| `build/name_entry.py`, `postcard.py` | English keyboards for name entry and postcards |
| `build/content_page.py`, `creel_hook.py`, `fishery.py`, `cs_names.py`, `map_labels.py` | Individual screens |
| `build/field_signs.py`, `title_logo.py`, `item_icons.py`, `gear_placeholders.py` | Graphics: town signs, the title logo, record icons and empty gear slots |
| `build/lzss.py`, `asm.py`, `knt2lib.py`, `jpkey.py`, `paths.py` | Libraries: compression, a 65816 assembler, text decoding, name-table keys, file locations |
| `build/*.tbl`, `kanji_overrides.txt`, `data/match_res2.pkl` | Character tables for decoding the Japanese font |
| `build/data/zones.pkl` | Offsets of the name lists in the ROM |
| `build/fonts/` | Source fonts: X11 `koi8x16` and `koi5x8` (public domain) and DejaVu Sans Bold (licence included) |
| `analysis/` | Research tools: disassembler (`dis.py`), 65816 interpreter and dialogue simulator (`cpu65816.py`, `sim*.py`), script dumper and reinserter, kanji matcher, and graphics finders in `gfx/` |
| `analysis/export_assets.py` | Renders the fonts and replaced graphics from your patched ROM into PNG sheets |
| `fonts_made/` | The fonts made for this patch, as PNG and raw data: the 8×16 dialogue font, the outlined 8×8 map-label font and the small hand-drawn pixel letters |
| `logo/` | The title logo (192×48, 15 colours) and a blank template for redrawing it |

## Left out on purpose
* **Original Japanese text.** `script.json` is generated from your ROM (see above). The name tables in `zones_en.py` and `user_edits.py` are keyed by a hash of the Japanese name (`jpkey.py`), so they still match what the build decodes from the ROM without storing the text itself.
* **RAM dumps and the kanji-usage cache.** `analysis/sim.py` needs a Mesen-S work-RAM dump saved as `build/data/sample_wram.dmp`. `analysis/apply.py`, `review.py` and `verify.py` need `build/data/usage.pkl`, which was built from the script during translation. Without those files, these tools won't run.
* **Poppins.** It was only used by `build/logo_art.py`, the generated fallback logo, which runs only when `build/logo_custom.png` is missing.
* **One-off experiment scripts** that depended on screenshots and dumps.
