# Characters and voice

Honorific policy: the game has no honorifics in its text (contemporary Japan, but the only speaker addresses the
player as あなた). If a later line needs one, keep it (contemporary Japanese setting) per the style guide.

## Fune Tarou (ふね太郎 / Fune Tarō)
- Role: the host. Speaks only in the opening speech after a new name is entered, and signs it ふね太郎.
- JP: friendly, casual-plain speech to the player (やあ！ こんにちは。 / 釣りに 出発だ！ / 健闘を 祈る。 / さようなら。).
- English voice: warm, chatty fishing buddy; contractions; short exclamations. "Well, hello there!" ... "Now, all aboard!
  Let's go fishing!" ... "Good luck out there! So long!"
- Signature: "Fune Tarō" (Hepburn, macron glyph is in the font).
- 太郎 is spelled Tarou in the project/folder name only (matches the No-Intro title).
