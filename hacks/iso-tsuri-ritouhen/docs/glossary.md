## Places
Island names are romanized. Short forms are used where the screen is narrow (map label, records menu, record
lines); the full name only on the big records heading.

| Japanese | Short | Full |
|---|---|---|
| 大島 | Oshima | Oshima |
| 利島 | Toshima | Toshima |
| 鵜渡根島 | Udone | Udoneshima |
| 新島 | Niijima | Niijima |
| 式根島 | Shikine | Shikinejima |
| 神津島 | Kozu | Kozushima |
| 銭洲 | Zenisu | Zenisu |
| 恩馳 | Onbase | islet off Kozushima |
| タダ苗 | Tadanae | islet off Kozushima |
| 下田港 | Shimoda | home port (angler list) |

Fishing spots (磯 names) are romanized from the kana readings the game gives in its records table: Hibaru,
Akaiwa, Senbazaki, Obanne, Tofu, Oone (大根 read おおね), Nazukata, Fuzushine, Chinohirane / Chinotakashima
(地の平根 / 地の高島), Tatamine, Katsuone, Domaru, Shoshinohana, Ohada, Nadara, Higashiboto, Saimane,
Hirakandachi, Hakamazaki Hanare / Omo, Nagatsuzaki, Naganne, Kado, Tadashima, Tatakine, Uchidaruma, Sotodaruma,
Sotohirattai, Ebine, Ishiyamane, Soto. Record lines abbreviate the longest ones with a period (Chinotaka.,
Higashibo., Hirakanda., S.Hirattai, Hakama-Han, Hakama-Omo).
